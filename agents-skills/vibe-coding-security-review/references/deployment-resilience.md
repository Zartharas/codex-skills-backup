# Deployment, Configuration, Exceptional Conditions, and Resilience

Review configuration that materially changes the runtime security boundary:

- debug/admin interfaces and verbose error responses
- environment separation and preview/staging access
- trusted proxies and client-IP handling
- origin/host allowlists
- insecure default credentials or anonymous modes
- object storage/database/network exposure
- exception paths that bypass auth/validation or fail open
- resource exhaustion, queue/backpressure, size/time limits and retry storms
- unsafe fallback behavior after dependency failure

Do not assume a missing application-layer control is absent from the deployed system; account for gateways, identity-aware proxies, WAF/CDN, service mesh, database policy, cloud IAM and managed-platform controls when evidence exists.

Separate deployment hardening from a source-code vulnerability unless the vulnerable configuration is actually present or reliably generated by the reviewed code.

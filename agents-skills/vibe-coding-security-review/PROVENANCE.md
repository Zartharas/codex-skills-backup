# Provenance and clean-room rewrite

Version 2.0.0 was independently rewritten for this package after reviewing multiple public security-skill designs and the user's earlier package.

- The earlier `vibe-coding-security-review` package disclosed that some reference material had been gap-filled from `ironsightscyber/vibe-security`, a GPL-3.0 repository.
- This v2 package does **not** copy or adapt that GPL-authored wording. Its references were rewritten from security principles and authoritative standards/documentation.
- `raroque/vibe-security-skill` (MIT) was reviewed as a packaging and scope comparison, but v2 uses an independently authored evidence-first workflow rather than reproducing its text.
- Specialist responsibilities are intentionally delegated to the separate supply-chain and AI/RAG/MCP skills instead of duplicating those workflows here.
